# smodeltrans 页面功能与重设计需求

> 对应路由和组件以当前源码为准。本文描述页面职责、状态、布局需求和必须保留的交互契约。

## 1. 主壳层

### 当前功能

主壳层位于 [`src/App.vue`](../src/App.vue)，负责：

- 无边框 titlebar
- 最小化、最大化、关闭
- 主导航
- 当前页面标题和状态标签
- 主题注入
- 后端状态和模型运行状态展示
- 页面 `KeepAlive`

主导航分为：

- 主要功能：实时翻译
- 工具：文本翻译、OCR、OCR 翻译
- 操作：设置、模型监控

### 重设计要求

首屏结构建议为：

```text
titlebar
  ↓
页面标题 / 全局状态
  ↓
当前页面主要任务
  ↓
辅助配置
  ↓
诊断或帮助信息
```

要求：

- 实时翻译是唯一一级主任务。
- 全局模型状态应保持可见，但不能抢占主要操作。
- 状态标签不能是唯一的状态反馈方式。
- 主窗口在 `720 × 560` 时仍必须能够切换页面。
- titlebar 的拖拽区和窗口按钮的 no-drag 区必须保留。
- 页面切换后应保留输入、图片预览和工作流状态。

## 2. 实时翻译页

路由：`/live-translation`

组件：[`src/components/LiveTranslationPage.vue`](../src/components/LiveTranslationPage.vue)

### 页面职责

实时捕获一个 Windows 窗口，按 ROI 识别字幕，通过 Hy-MT2 翻译，并将译文显示在字幕浮层或目标窗口的逐区替换层中。

### 核心功能

1. 刷新并选择目标窗口。
2. 输入目标语言。
3. 开始实时翻译。
4. 默认使用目标窗口完整客户区作为 ROI。
5. 运行中暂停、继续、停止。
6. 运行中重新选择 ROI。
7. 选择字幕框或逐区坐标替换模式。
8. 调整字幕显示样式和尺寸。
9. 配置实时翻译提示词和上下文记忆。
10. 配置自动识别或按键触发。
11. 查看实时指标和调试记录。

### 状态

| 状态 | 用户需要知道的内容 | 主要动作 |
| --- | --- | --- |
| `idle` | 尚未开始会话 | 选择窗口、设置语言、开始 |
| `selecting` | 正在选择字幕区域 | 确认或取消区域选择 |
| `warming` | OCR 和翻译模型正在准备 | 等待或停止 |
| `running` | 会话正在持续处理 | 暂停、重新选择区域、停止 |
| `paused` | 会话暂时停止处理 | 继续、重新选择区域、停止 |
| `stopping` | 会话正在关闭 | 等待完成 |
| `error` | 会话没有继续运行 | 查看原因、重新开始 |

### 配置范围

#### 首屏必要配置

- 目标窗口
- 目标语言
- 开始实时翻译

#### 显示配置

- `subtitle`：字幕框附着在目标窗口外侧
- `region_replace`：在目标客户区内逐区替换
- 贴附边
- 外侧偏移
- 显示 OCR 原文
- 显示译文框体
- 自动宽度和高度
- 手动宽度和高度
- 字体颜色
- 字体大小
- 背景颜色
- 背景透明度

#### 翻译配置

- 实时补充提示词
- 上下文记忆开关
- 上下文 token 预算
- 保留轮数

#### 识别配置

- 自动识别
- 按键触发
- 触发按键
- 按下或松开触发
- 字幕稳定等待
- 按键触发超时
- 相邻文本合并

#### 诊断信息

- 捕获帧数
- 丢弃帧数
- ROI 未变化跳过数
- OCR 次数
- 翻译次数
- 字幕发布数
- 最近 OCR 耗时
- 最近翻译耗时
- GPU 名称和显存
- 最多 200 条 OCR 与翻译记录

### 推荐布局

```text
实时翻译
├── 会话准备
│   ├── 目标窗口
│   ├── 目标语言
│   └── 开始实时翻译
├── 当前会话
│   ├── 状态
│   ├── 目标窗口摘要
│   ├── 当前 ROI
│   ├── 暂停 / 继续
│   ├── 重新选择区域
│   └── 停止
├── 启动前配置
│   ├── 显示
│   ├── 翻译
│   └── 识别
└── 运行诊断
    ├── 实时指标
    └── OCR 与翻译记录
```

### 关键设计要求

- 首屏不展示完整的高级配置表单。
- 开始运行后，页面视觉重心切换到当前会话。
- 明确标注哪些设置只在下一次会话生效。
- 运行错误必须给出恢复路径。
- 捕获模式、独占全屏限制和 OCR 支持边界应放在目标窗口附近。
- `region_replace` 的坐标限制必须紧邻显示模式选项。
- 诊断区域默认降低权重或折叠，不能压过开始和停止操作。

## 3. 文本翻译页

路由：`/translate`

组件：[`src/components/TextTranslationPage.vue`](../src/components/TextTranslationPage.vue)

### 页面职责

直接输入文本，使用 Hy-MT2 翻译，不经过 OCR。

### 核心功能

- 输入或粘贴文本
- 设置目标语言
- `Ctrl + Enter` 或 `Command + Enter` 开始
- 清空输入
- 开始翻译
- 取消翻译
- 再次翻译
- 查看流式进度
- 查看 provider 和耗时
- 复制译文
- 保存 `.txt`

### 状态

- `idle`
- `processing`
- `result`
- `cancelled`
- `error`

取消和错误后必须保留输入内容，并允许重新开始。

### 推荐布局

```text
文本翻译
├── 输入文本
│   ├── 文本编辑区
│   ├── 目标语言
│   ├── 快捷键提示
│   └── 清空 / 开始 / 取消
└── 翻译结果
    ├── 进度或空状态
    ├── 译文
    ├── provider / 耗时
    └── 复制 / 保存
```

### 快捷翻译配置

当前快捷翻译开关和快捷键选择位于文本翻译页。重设计建议：

- 设置页增加独立的“快捷翻译”全局设置区域。
- 文本翻译页保留紧凑的快捷键状态入口。
- 保留当前快捷键选项：
  - `Ctrl + Alt + E`
  - `Ctrl + Alt + T`
  - `Ctrl + Shift + E`
  - `Alt + Shift + E`
- 如果迁移配置位置，不能丢失现有持久化设置和入口可发现性。

## 4. OCR 页

路由：`/ocr`

组件：[`src/components/OcrPage.vue`](../src/components/OcrPage.vue)

### 页面职责

从图片中提取文字，不执行翻译。

### 核心功能

- 拖放图片
- 浏览文件
- `Ctrl + V` 粘贴图片
- 输入图片预览
- 选择其他图片
- 开始 OCR
- 取消和再次识别
- 显示 OCR 标注图
- 打开大图后按区域选字
- 查看识别文本
- 查看 Markdown
- 复制内容
- 保存文本
- 保存 PNG

### 状态

- `idle`
- `preview`
- `processing`
- `result`
- `cancelled`
- `error`

### 推荐布局

```text
OCR
├── 输入图片
│   ├── 拖放区
│   ├── 文件选择
│   ├── 粘贴提示
│   ├── 图片预览
│   └── 开始 OCR
└── 识别结果
    ├── 标注图片
    ├── 放大选字提示
    ├── 识别文本 / Markdown
    ├── 复制
    ├── 保存文本
    └── 保存 PNG
```

### 关键设计要求

- 上传前和上传后的输入区结构保持连续。
- 图片预览是主要内容，文件信息不能占据主要视觉面积。
- 文本和 Markdown 需要明确区分输出模式。
- 选字提示应在结果图附近持续可见。
- 取消和错误时保留图片预览。

## 5. OCR 翻译页

路由：`/ocr-translate`

组件：[`src/components/OcrTranslationPage.vue`](../src/components/OcrTranslationPage.vue)

### 页面职责

从图片识别文字并使用 Hy-MT2 翻译。

### 核心功能

- 上传图片
- 图片预览
- 开始翻译
- 取消和再次尝试
- 显示 OCR 与翻译进度
- 显示标注翻译图
- 显示文本结果
- 复制文本
- 保存文本
- 保存 PNG

### 特殊能力状态

CPU 模式可能只能得到 OCR 结果，不能完成 Hy-MT2 翻译。界面必须明确区分：

- OCR 已完成
- 翻译已完成
- 仅得到 OCR 结果
- Hy-MT2 不可用
- CUDA 未启用

OCR-only 不能显示为完整翻译成功。

### 推荐布局

```text
OCR 翻译
├── 图片输入
│   ├── 拖放或选择
│   ├── 图片预览
│   └── 开始翻译
└── 翻译输出
    ├── OCR / 翻译阶段进度
    ├── 标注翻译图
    ├── 原文或译文文本
    └── 复制 / 保存
```

负责模型路径、主题、默认语言、提示词、运行资源和高级模型参数。

- 标注字体

- 设备
- OCR 并发
- Hy 批大小
- 空闲释放时间

#### 高级生成参数

- sampling
- max new tokens
- temperature
- top-k
- top-p
- seed
- repetition penalty
- frequency penalty
- stop tokens
- stop strings

#### 记忆参数

- 记忆开关
- token 预算
- 记忆轮数

### 推荐布局

```text
设置
├── 模型准备
├── 常用偏好
├── 快捷翻译
├── 运行资源
├── 模型服务状态
└── 高级生成与记忆
```

### 关键设计要求

- 常用设置和高级设置必须渐进披露。

- 显示未保存修改状态。
- 显示后端实际读取值，不伪造模型就绪。
- 长模型路径支持截断、悬停查看和复制。
- 保存和刷新操作需要固定且明确。

## 7. 模型监控页

路由：`/model-monitor`

组件：[`src/components/ModelMonitorPage.vue`](../src/components/ModelMonitorPage.vue)

### 页面职责

提供模型驻留控制和运行时诊断，不承担普通翻译任务。

### 核心功能

- Runtime busy / idle
- 当前设备
- 已驻留模型数量
- OCR 加载和卸载
- Hy-MT2 加载和卸载
- 模型路径
- 请求总数
- 成功和失败请求
- 成功率
- 平均和最近耗时
- 空闲计时
- 最近运行事件表
- 自动刷新和手动刷新

### 推荐布局

```text
模型监控
├── Runtime 总览
├── 模型驻留
│   ├── PP-OCR
│   └── Hy-MT2
├── 运行指标
└── 最近运行记录
```

### 关键设计要求

- busy 状态必须位于页面上方。
- 模型控制按钮必须说明不可用原因。
- 运行事件表保留时间、操作、状态、耗时、说明。
- 自动刷新间隔和最后刷新时间需要可见。
- 保持运维页面的信息密度，不引入装饰性大组件。

## 8. 页面通用交互契约

所有一次性工作流都必须遵循：

```text
idle → preview → processing → result
                    ├→ cancelled
                    └→ error
```

具体要求：

- `processing` 时显示可理解的阶段和进度。
- 取消后保留输入或预览。
- 错误后保留可恢复操作。
- 结果区的复制、保存按钮必须有成功或失败反馈。
- 不依赖颜色单独表达状态。
- 浏览器预览中保留桌面端能力提示。
- 关键状态通过 `aria-live` 暴露。
