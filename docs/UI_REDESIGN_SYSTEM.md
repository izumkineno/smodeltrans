# smodeltrans UI 设计系统与交互约束

> 本文是主工作台和透明浮层重设计的共享约束。具体页面职责见 [`UI_REDESIGN_PAGES.md`](./UI_REDESIGN_PAGES.md)，浮层职责见 [`UI_REDESIGN_OVERLAYS.md`](./UI_REDESIGN_OVERLAYS.md)。

## 1. 设计方向

`smodeltrans` 是本地推理工具，不是营销型 SaaS 页面。

推荐方向：

- 工具型工作台
- 信息层级清晰
- 主要操作靠前
- 结果优先
- 配置渐进披露
- 运行状态明确
- 透明浮层高对比

避免：

- 所有内容都放入等权卡片
- 主页面堆叠大量高级参数
- 紫蓝渐变、玻璃拟态和大面积装饰性光晕
- 只用颜色表达运行状态
- 依赖 hover 才能发现关键操作
- 将快捷翻译框做成实时翻译控制面板

### 使用规则

- 颜色必须使用语义 token，不要在页面中散落硬编码颜色。
- 主界面保持一套主色。
- 透明浮层使用独立的高对比控制 token。
- 用户配置的字幕背景色和透明度属于内容样式，不应覆盖全局状态色。
- 文字和交互控件至少满足 WCAG AA 对比度。

## 3. 字体与排版

当前字体栈：

```css
"Microsoft YaHei", "PingFang SC", "Noto Sans SC", "Segoe UI", ui-sans-serif, system-ui, sans-serif
```

要求：

- 优先保证中文、日文和拉丁文字混排稳定。
- 正文不能过小，辅助文字必须保持可读。
- 页面说明使用较短句子，避免长段落压过操作。
- 译文是字幕框的最高文字层级。
- 原文应使用较小字号和较低对比度，但不能低到无法辨认。
- 字幕文本使用 `pre-wrap` 和 `overflow-wrap: anywhere`，处理多行和长单词。
- 行高必须覆盖中文字体的实际字面高度，避免上下裁切。
- 处理中的状态文案要短，优先显示当前阶段而不是内部日志。

现有字幕默认字体大小为 `24px`，原文约为译文的次级比例。后续设计可调整数值，但必须保留译文和原文的层级关系。

## 4. 间距、圆角和表面

建议使用 8px 间距体系：

- `4px`：图标和紧凑控件内部间距
- `8px`：标签、按钮和字段间距
- `16px`：卡片内部和普通区块间距
- `24px`：页面主要区块间距
- `32px`：首屏任务分组间距

建议统一圆角层级：

- 小控件：`4px` 到 `6px`
- 普通面板：`8px` 到 `12px`
- 透明字幕框：可使用更大的圆角，但必须确保小窗口不显得松散

不要同时叠加多层嵌套卡片、强边框和重阴影。主界面可使用边框区分层级，浮层才使用明显阴影分离背景。

## 5. 页面布局规则

### 主工作台

- 页面主要任务必须在首屏。
- 辅助设置使用分组、折叠或标签页。
- 同一页面最多保留一个主要 CTA。
- 结果区动作固定在结果附近。
- 页面滚动区应独立于 titlebar 和导航。
- 诊断信息不应默认展开到首屏。

### 一次性工具

统一采用：

```text
输入区 + 输出区
```

在宽窗口中并排，在窄窗口中纵向堆叠。输入、预览、进度和结果的尺寸变化不能导致整个页面跳动。

### 设置页

采用渐进披露：

```text
常用配置 → 运行资源 → 高级生成 → 记忆和停止条件
```

每项设置必须显示作用范围、默认值或当前生效值，以及生效时机。

### 模型监控页

采用运维仪表盘结构：

```text
Runtime 状态 → 模型驻留 → 指标 → 事件表
```

保持数据密度，减少装饰性内容。

## 6. 浮层 token

透明浮层与主工作台分开定义 token：

| 语义 | 推荐方向 |
| --- | --- |
| 控制栏背景 | 深色高不透明度 |
| 控制栏文字 | 接近白色 |
| 主译文 | 高对比、较高字重 |
| 原文 | 同色相但降低对比度 |
| 进度色 | 使用单一明亮强调色 |
| 关闭按钮 | 始终可见、背景独立 |
| 浮层边界 | 轻边框加阴影 |

注意：浮层背景可以透明，但译文不能依赖目标窗口背景提供对比度。用户自定义字幕背景透明度时，需要保证极端配置仍可阅读或明确提示风险。

## 7. 状态表达

状态必须同时通过文字、结构和适度颜色表达。

### 实时翻译

```text
未启动 → 选择区域 → 模型预热 → 实时运行 → 暂停 → 停止
                                      └→ 错误
```

### 一次性工作流

```text
等待输入 → 预览 → 处理中 → 结果
                     ├→ 已取消
                     └→ 错误
```

要求：

- 处理中显示当前阶段和进度。
- 取消显示内容保留和重试动作。
- 错误显示原因和下一步。
- 成功显示结果和后续动作。
- 不使用纯色点或纯色标签代替完整状态。

## 8. 交互和无障碍

必须保留：

- 所有按钮的可见焦点。
- 键盘可完成主要操作。
- `Enter` 和 `Esc` 的既有行为。
- 交互控件的 aria label。
- 进度、错误和完成状态的 `aria-live`。
- 拖放区域的键盘替代方式。
- 图片预览的替代文本。
- 颜色以外的状态表达。
- `prefers-reduced-motion` 支持。

快捷翻译框特别要求：

- Esc 关闭并取消当前请求。
- 关闭按钮不能被内容覆盖。
- 复制按钮必须有清晰的成功反馈。
- 文本可选择复制，但工具栏不应抢占文本选择。

## 9. 响应式和关键尺寸

必须验证以下尺寸：

| 场景 | 尺寸 | 关注点 |
| --- | --- | --- |
| 主窗口默认 | `1180 × 760` | 首屏主要任务和侧栏层级 |
| 主窗口最小 | `720 × 560` | 导航替代方案和内容滚动 |
| 快捷翻译默认 | `320 × 104` | 关闭、译文和复制的空间关系 |
| 快捷翻译最小 | `160 × 72` | 极短译文、错误和关闭 |
| 长文本 | 视口受限 | 框内滚动而不是无限撑大 |
| 多行 CJK | 视口受限 | 行高、换行和动态尺寸 |

当前页面在 `900px` 附近切换单列，在 `720px` 附近隐藏侧栏，在 `560px` 附近进一步压缩。重设计必须重新验证这些断点，而不能只沿用 CSS 数值。

## 10. 技术耦合与设计风险

### 10.1 共享字幕组件

`LiveSubtitlePanel.vue` 同时服务快捷翻译和实时字幕。修改以下内容会同时影响两种浮层：

- padding
- 字体大小
- 工具栏高度
- 关闭按钮位置
- 进度栏
- 内容最大宽高
- 滚动策略

建议先定义 `quick` 和 `live` 变体，再分别调整样式。

### 10.2 动态尺寸反馈

快捷翻译框使用 `ResizeObserver` 和 Tauri `setSize` 根据内容调整窗口。以下情况需要防抖和边界控制：

- 流式译文不断增长
- 进度文案变化
- 长文本换行
- 内容达到最大高度
- 窗口即将关闭

### 10.3 坐标替换模式

`region_replace` 依赖目标客户区、ROI 局部坐标和识别区域坐标之间的映射。任何外围 padding、边框或布局偏移都可能破坏 1:1 显示。

### 10.4 配置持久化

以下设置存在跨页面共享或持久化关系：

- target language
- live overlay
- subtitle style
- recognition
- live translation prompt and memory
- quick translation enabled and shortcut
- backend and model runtime status

重排页面不能改变这些设置的作用范围和保存语义。

## 11. 手动验证清单

### 主 UI

- [ ] `1180 × 760` 下实时翻译目标窗口和开始按钮位于首屏。
- [ ] `720 × 560` 下仍能切换所有页面。
- [ ] light 和 dark 主题的主要文字和控件满足对比度要求。
- [ ] titlebar 可以拖动，窗口按钮可以独立操作。
- [ ] 页面切换后输入和图片预览保持。

### 实时翻译

- [ ] idle、warming、running、paused、error 状态均有清晰布局。
- [ ] 运行中暂停、继续、重新选择区域、停止操作可见。
- [ ] 显示、翻译、识别配置不会压过会话控制。
- [ ] 诊断数据默认不会挤压首屏。

### 快捷翻译框

- [ ] 默认尺寸 `320 × 104` 可读。
- [ ] 最小尺寸 `160 × 72` 不遮挡关闭按钮。
- [ ] 译文在上，原文在下。
- [ ] processing、result、error 状态均不残留旧内容。
- [ ] 长文本在框内滚动，不撑满整个屏幕。
- [ ] 复制和关闭按钮始终可用。
- [ ] Esc 可以关闭并取消请求。

### 实时字幕框

- [ ] hover、focus、pinned 工具栏状态可用。
- [ ] 固定工具栏不会遮挡译文。
- [ ] 自动尺寸和手动尺寸不会互相覆盖。
- [ ] OCR 和翻译进度表达清晰。

### 坐标与选择器

- [ ] `region_replace` 保持目标客户区 1:1 坐标。
- [ ] ROI 选择器显示尺寸和目标窗口。
- [ ] Enter 确认，Esc 取消。
- [ ] 无效选区无法确认。
