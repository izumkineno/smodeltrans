# smodeltrans 字幕框与快捷翻译浮层需求

> 本文专门描述快捷翻译框、实时字幕框、逐区替换覆盖层和 ROI 选择窗口。
>
> 当前共享实现：[`src/components/LiveSubtitlePanel.vue`](../src/components/LiveSubtitlePanel.vue)

## 1. 浮层类型

```text
辅助窗口
├── 快捷翻译框
├── 实时字幕框
├── 逐区坐标替换覆盖层
└── ROI 区域选择窗口
```

四者的使用时长、交互方式和布局约束不同，不能只依赖一套 CSS。

## 2. 快捷翻译框

组件：[`src/components/QuickTranslationOverlay.vue`](../src/components/QuickTranslationOverlay.vue)

窗口配置位于 [`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json)：

- 初始尺寸：`320 × 104`
- 最小尺寸：`160 × 72`
- 透明背景
- always-on-top
- skip taskbar
- 不可调整大小
- 默认不可见
- 根据内容动态调整尺寸

### 2.1 功能流程

```text
其他应用选中文字
    ↓
按全局快捷键
    ↓
UI Automation 读取选区
    ↓
显示快捷翻译框
    ↓
本地翻译模型处理
    ↓
显示译文
    ↓
复制或关闭
```

### 2.2 状态

| 状态 | 显示目标 | 必须提供 |
| --- | --- | --- |
| `idle` | 等待下一次快捷键触发 | 简短等待提示 |
| `processing` | 让用户知道请求仍在进行 | 当前阶段、轻量进度 |
| `result` | 让用户快速阅读译文 | 复制、关闭 |
| `error` | 解释选区或翻译失败 | 错误文本、关闭或再次触发 |

### 2.3 推荐布局

```text
┌──────────────────────────────┐
│                         关闭 │
│                              │
│  译文主区域                  │
│  翻译结果应首先被看到        │
│                              │
│  原文次区域                  │
│  保持上下文但降低权重        │
│                              │
│                 [复制]       │
└──────────────────────────────┘
```

推荐内容顺序：

1. 译文
2. 原文
3. 处理中状态或进度
4. 复制操作
5. 关闭操作

### 2.4 快捷翻译框必须满足

- 译文使用最高视觉层级。
- 原文作为次级信息显示在译文下方。
- 正常状态不显示实时字幕的 ROI、尺寸和识别工具栏。
- 右上角关闭按钮始终可见且可点击。
- 翻译完成后复制按钮必须高可见。
- 长文本不能无限撑大窗口。
- 长文本应在框内滚动，窗口尺寸应有最大宽度和最大高度。
- 动态调整尺寸需要去抖，不能随每个流式 token 产生明显抖动。
- CJK 多行、英文长单词和混合文本都不能溢出窗口。
- Esc 必须关闭窗口。
- 关闭窗口时应取消当前翻译并释放监听。
- 选区读取失败时不能显示旧请求的译文。

### 2.5 快捷翻译框不应出现

- 实时字幕专属工具栏
- 重新选择 ROI
- 自动宽度、高度按钮
- 手动宽高输入
- 实时上下文记忆设置
- 运行指标
- OCR 区域框调试
- 复杂的多级设置菜单

快捷翻译框的唯一任务是快速显示当前选区的翻译。

## 3. 实时字幕框

组件：[`src/components/LiveSubtitleOverlay.vue`](../src/components/LiveSubtitleOverlay.vue)

共享内容组件：[`src/components/LiveSubtitlePanel.vue`](../src/components/LiveSubtitlePanel.vue)

### 3.1 功能流程

```text
实时会话启动
    ↓
模型预热
    ↓
OCR 识别
    ↓
字幕翻译
    ↓
更新译文和原文
    ↓
持续运行，直到暂停或停止
```

### 3.2 内容层级

- 译文：主层级，字号最大，优先阅读。
- 原文：次层级，显示在译文下方。
- 进度：只在预热、OCR、翻译处理中显示。
- 错误：位于内容区域附近，并保持高对比度。
- 关闭：固定在右上角。

### 3.3 实时工具栏

工具栏当前在以下情况出现：

- hover
- focus-within
- pinned
- native resizing

工具栏包含：

- 手动框选翻译区域
- 开关自动宽度
- 开关自动高度
- 编辑字幕尺寸
- 固定或取消固定工具栏
- 手动输入宽度和高度

### 3.4 推荐布局

默认运行时：

```text
┌──────────────────────────────┐
│                              ×│
│                              │
│          译文                │
│          原文                │
│                              │
└──────────────────────────────┘
```

鼠标移入或键盘聚焦时：

```text
┌────工具栏──────────────────×──┐
│                              │
│          译文                │
│          原文                │
└──────────────────────────────┘
```

固定工具栏时，内容区必须为工具栏预留空间，不能遮挡译文。

### 3.5 实时字幕框必须满足

- 默认保持简洁，工具栏不持续占据内容区。
- 工具栏按钮必须有 tooltip、可见焦点和 aria label。
- 工具栏可以横向滚动，但不能撑破窗口边界。
- 关闭、拖动、重选区域、尺寸编辑等控件互不遮挡。
- 进度应区分 OCR 和翻译阶段。
- 字幕持续更新时，尺寸变化不能明显闪烁。
- 译文和原文使用稳定的上下位置，避免更新后跳序。
- 长字幕在固定高度模式下只在内容区滚动。
- 手动尺寸模式下不能因内容变化自动覆盖用户尺寸。
- 透明背景和用户设置的背景透明度不能降低文字可读性。

## 4. 逐区坐标替换覆盖层

组件：[`src/components/LiveRegionReplaceOverlay.vue`](../src/components/LiveRegionReplaceOverlay.vue)

### 功能

- 覆盖目标窗口客户区。
- 按 OCR 区域绘制译文。
- 可选显示 OCR 原文。
- 可选显示译文区域框。
- 与目标客户区保持 1:1 坐标关系。

### 设计约束

- 不增加会改变坐标映射的外围 padding。
- 不使用会改变文本区域位置的卡片边框。
- 译文背景、行高和字体缩放必须在区域内部处理。
- 调试框只能作为可选状态，不应成为默认视觉。
- 覆盖层不能遮挡目标窗口之外的内容。
- 必须保留区域边界裁切和窗口缩放后的相对位置。

## 5. ROI 选择窗口

组件：[`src/components/LiveSelectionWindow.vue`](../src/components/LiveSelectionWindow.vue)

### 功能

- 全屏暗幕覆盖。
- 鼠标拖拽框选区域。
- 显示选区像素尺寸。
- Enter 确认选区。
- Esc 取消选区。
- 显示目标窗口名称和当前状态。

### 推荐布局

```text
全屏暗幕
├── 中央或底部操作说明
├── 当前选区矩形
├── 选区像素尺寸
└── 取消 / 确认选区
```

### 设计要求

- 暗幕不能完全隐藏目标内容，必须能看清字幕区域。
- 选区边框与暗幕保持足够对比度。
- 当前选区宽高必须使用物理像素表达。
- 确认按钮在选区无效时禁用，并说明原因。
- 键盘操作和按钮操作保持一致。
- 不得让说明栏遮挡用户正在框选的区域。

## 6. 快捷翻译框与实时字幕框的共享和差异

| 能力 | 快捷翻译框 | 实时字幕框 |
| --- | --- | --- |
| 译文在上、原文在下 | 保留 | 保留 |
| 关闭按钮 | 始终显示 | 始终显示 |
| 复制按钮 | 结果状态显示 | 不作为默认主操作 |
| OCR / 翻译进度 | 轻量显示翻译进度 | 显示 OCR 与翻译阶段 |
| 动态窗口尺寸 | 必须 | 可选，受用户设置控制 |
| ROI 工具栏 | 不显示 | hover / focus / pinned 显示 |
| 拖动窗口 | 回字形拖动区域 | 回字形拖动区域 |
| 重新选择 ROI | 不显示 | 工具栏提供 |
| 手动宽高 | 不显示 | 工具栏提供 |
| 运行指标 | 不显示 | 不放在浮层中，回主 UI 查看 |
| 长文本 | 限高滚动 | 按自动或手动尺寸处理 |

实现层面建议使用明确的 variant 或 sizing mode，而不是依赖全局 CSS 选择器猜测当前窗口类型。

## 7. 浮层验证状态

重设计至少需要验证：

1. 快捷翻译框最小尺寸 `160 × 72`。
2. 快捷翻译框默认尺寸 `320 × 104`。
3. 长中文、多行中文、英文长单词和混合文本。
4. `processing` 状态的动态尺寸变化。
5. `result` 状态的复制按钮和关闭按钮。
6. `error` 状态不会残留上一次译文。
7. 实时字幕框 hover、focus、pinned 三种工具栏状态。
8. 固定工具栏不会遮挡译文。
9. 实时字幕框手动尺寸不会被内容自动覆盖。
10. `region_replace` 模式的区域坐标保持 1:1。
11. ROI 选择窗口的 Enter、Esc 和鼠标操作。
